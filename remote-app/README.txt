============================================================
  SAP Logistics Hub - הוראות התקנה למחשב נוסף ברשת
============================================================

המערכת רצה על מחשב מרכזי בכתובת:
   http://192.168.0.14:4000

התיקייה הזו מאפשרת להתקין קיצורים על מחשב שני
(או יותר) שנמצא באותה רשת מקומית (LAN).


============================================================
  שיטה 1 - התקנה מהירה (מומלץ)
============================================================

1. העתק את כל התיקייה "remote-app" למחשב היעד
   (למשל בעזרת Disk-On-Key, רשת משותפת, או OneDrive).

2. במחשב היעד, לחץ דאבל-קליק על:
      Install.bat

3. ייווצרו 3 קיצורים על שולחן העבודה:
      - SAP Logistics Hub        (מערכת ראשית)
      - SAP Logistics - Driver   (כניסת נהגים)
      - SAP Logistics - Admin    (כניסת מנהלים)

4. דאבל-קליק על אחד מהם => הדפדפן יפתח את המערכת.


============================================================
  שיטה 2 - העתקה ידנית של קיצור
============================================================

אם רק רוצים קיצור אחד:

1. בתוך התיקייה הזו תמצא:
      SAP Logistics Hub.url
2. גרור או העתק אותו לשולחן העבודה של המחשב השני.
3. דאבל-קליק => פותח את המערכת.


============================================================
  פרטי התחברות
============================================================

   משתמש : admin
   סיסמה : admin123

(אפשר לשנות בדף "משתמשים" אחרי הכניסה הראשונה)


============================================================
  בדיקת חיבור - אם הקיצור לא עובד
============================================================

1. ודא ששני המחשבים נמצאים באותה רשת (אותו ראוטר/Wi-Fi).

2. במחשב היעד, פתח דפדפן והכנס לכתובת:
      http://192.168.0.14:4000
   אם זה לא עובד => המחשב המארח כבוי, או שה-Firewall חוסם.

3. במחשב המארח (192.168.0.14):
   - ודא שהשרת רץ (חלון שחור עם demoServer פתוח).
   - אם לא רץ - דאבל-קליק על:
        🚛 SAP Logistics Hub
     שעל שולחן העבודה.

4. אם החיבור עדיין נכשל - הרץ במחשב המארח כ-Administrator
   את הסקריפט:
        open-firewall.ps1
   הוא יפתח את פורט 4000 ב-Windows Firewall.


============================================================
  גישה מהטלפון (נהגים)
============================================================

נהגים יכולים להיכנס מטלפון שמחובר ל-Wi-Fi של המשרד:
   http://192.168.0.14:4000/driver/login


============================================================
  בעיות?
============================================================

אם משהו לא עובד - דבר עם בעל המערכת.
המערכת תוכננה לעבוד ברשת מקומית בלבד (לא דרך האינטרנט).
