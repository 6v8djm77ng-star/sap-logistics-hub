## 🔴 קריטי - חייב לתקן

### 1. ניקוי בילדים ישנים בתיקיית `dist/`
**הבעיה:**
התיקייה `frontend/dist/assets/` מכילה **42 קבצי JS** (~46MB), מה שגורם:
- ה-PWA Service Worker מנסה לקבץ את **כולם** בקאש ⚠
- הטלפון של הנהג מוריד 30+ MB מיותרים
- בנייה איטית ועוד יותר איטית עם הזמן

**תיקון:**
```bash
# מחיקה אוטומטית של בילדים ישנים לפני כל בנייה
cd frontend && rm -rf dist && npm run build
```
**או** הוספה ל-`vite.config.js`: `emptyOutDir: true`

**השפעה:** 🔴 גבוהה | **מאמץ:** 🟢 קל (5 דק׳)

---

### 2. JWT Secret עדיין ברירת מחדל
**הבעיה:**
`backend/.env` מכיל:
```
JWT_SECRET=a-very-long-random-secret-change-this-in-production-12345
```
זה גלוי בקוד הפתוח של GitHub והופך **כל טוקן** לפריצה - מי שמכיר את הסטרינג יכול ליצור טוקן admin!

**תיקון:**
```bash
node -e "console.log(require('crypto').randomBytes(64).toString('hex'))"
# מעתיק את הפלט ל-JWT_SECRET ב-.env
```

**השפעה:** 🔴 קריטית באבטחה | **מאמץ:** 🟢 קל (2 דק׳)

---

### 3. Bundle יחיד 1.2MB - אין Code Splitting
**הבעיה:**
כל הקבצים נארזים בקובץ JS אחד של **1.2MB** (גזיפ: 347KB).
טלפון איטי או רשת חלשה → **5+ שניות** רק לטעון את האפליקציה.

**תיקון:**
ב-`vite.config.js` הוסף manual chunks:
```js
build: {
  rollupOptions: {
    output: {
      manualChunks: {
        'react-vendor': ['react', 'react-dom', 'react-router-dom'],
        'ui-vendor':    ['lucide-react', 'sonner', 'clsx'],
        'tanstack':     ['@tanstack/react-query'],
        'date-utils':   ['date-fns'],
      },
    },
  },
},
```
**תוצאה:** 4 chunks קטנים, נטענים במקביל. טעינה ראשונית 2 שניות במקום 5.

**השפעה:** 🔴 גבוהה (UX נהגים) | **מאמץ:** 🟡 בינוני (15 דק׳)

---

### 4. אחסון ב-JSON - מתקרב לגבולות
**הבעיה:**
`backend/data/store.json` כבר 1.6MB. עם הצמיחה (1,265 שורות הזמנה ב-46 מסלולים בשבוע), יגיע ל-**10MB תוך חודשיים**.
- כל שמירה כותבת מחדש את כל הקובץ
- אין אינדקסים, חיפוש לפי StopId הוא O(n)
- אין transaction safety

**תיקון:**
מעבר ל-**SQLite** (פשוט, קובץ יחיד, יציב, אפשר להריץ עליו SQL):
```bash
npm install better-sqlite3
```
זמן שיפוץ: ~2 ימים. שווה את ההשקעה.

**השפעה:** 🔴 גבוהה (יציבות לטווח ארוך) | **מאמץ:** 🔴 קשה (יומיים)

## 🟡 חשוב - לתקן בקרוב

### 5. אין Rate Limiting על endpoints
מי שיודע את הכתובת יכול **לשלוח 1000 בקשות בשנייה**. SAP יקרוס.

**תיקון:**
```bash
npm install express-rate-limit
```
```js
import rateLimit from 'express-rate-limit';
const apiLimiter = rateLimit({ windowMs: 60_000, max: 200 });
app.use('/api/', apiLimiter);
```

**השפעה:** 🟡 בינונית (מגן על SAP) | **מאמץ:** 🟢 קל

## 🟢 שיפורי UX וויעול

### 9. אין דף "מה חדש" / Changelog למשתמש
אתה משדרג כל יום, אבל אביעד והנהגים לא יודעים מה השתנה. תוסיף "🎉 חדש" בולט באייקון התראה.

### 10. אין Keyboard Shortcuts
- `/` - למיקוד תיבת חיפוש
- `Esc` - סגירת דיאלוג
- `Ctrl+K` - command palette גלובלי
*Boost ל-power users*

### 11. אין Undo
מחיקת מסלול = אין דרך חזרה. הוסף **Toast עם "Undo" 5 שניות**.

### 12. ה-Wallboard לא מתחלף לבד בין אזורים
מסך גדול במשרד יראה רק עכשיו. הוסף החלפה אוטומטית כל 30 שניות בין: היום, השבוע, נהגים פעילים.

### 13. אין PDF להזמנה ספציפית
משלוח לא מוצלח? הנהג רוצה לראות את ההזמנה המקורית. הוסף **GET `/api/orders/:company/:docEntry/pdf`**.

### 14. אין דאשבורד ל-COD בזמן אמת
היום צריך לפתוח דף נפרד. הוסף **ווידג'ט בדשבורד הראשי**: כמה כסף נגבה היום, כמה ממתין להפקדה.

### 15. אין התראת SMS אוטומטית לנהג
היום הנהג מתחבר דרך הטלפון. הוסף **SMS בבוקר**: "המסלול שלך מוכן: [קישור]" - חוסך התקשרות בוקר.

### 20. תמיכה בריבוי שפות
