# SAP Logistics Hub - מדריך שימוש

## 🚀 איך להפעיל את המערכת?

### הפעלה יומיומית:
דבל-קליק על הקיצור בשולחן העבודה:

**🔗 SAP Logistics - Open** (דפדפן נפתח ישר למערכת)

או:

**🚛 SAP Logistics Hub** (מפעיל שרת + דפדפן)

### אם השרת לא פעיל:
1. לחץ על **🚛 SAP Logistics Hub** בשולחן העבודה
2. חלון שחור ייפתח - תן לו כמה שניות
3. הדפדפן ייפתח אוטומטית

### לעצור:
לחץ על **⏹ Stop SAP Logistics Hub** בשולחן העבודה.

## 🔐 התחברות

- **משתמש:** `admin`
- **סיסמה:** נקבעת בעת ההתקנה ונשמרת אצל מנהל המערכת בלבד (Bitwarden / כספת ארגונית). אסור לתעד סיסמאות בקוד או במסמכים.

ניתן לשנות סיסמה בדף "משתמשים" → איפוס סיסמה.

---

## 📋 זרימת עבודה יומית מומלצת

### 🌅 בוקר:
1. פתח **"תכנון יומי"**
2. לחץ **"תכנון אוטומטי"** - המערכת יוצרת מסלולים לפי אזור מההזמנות ב-SAP
3. פתח **"מסלולי הפצה"** ושייך נהג לכל מסלול
4. **"הדפס את כל המסלולים"** (PDF) - תדפיס לנהגים

### 🏭 מחסן:
1. פתח **"ליקוט מחסן"**
2. בחר מסלול → **"צור גל ליקוט"**
3. סרוק ברקוד או סמן ידנית פריטים
4. כשסיימת - המסלול עוברת אוטומטית ל"הועמס"

### 🚚 הפצה:
- נהגים מתחברים ב-`http://192.168.0.14:4000/driver/login` מהטלפון
- מקבלים רשימת עצירות עם ניווט Google Maps
- מסמנים "הגעתי" → "חתום וסיים"

### 🌙 סוף יום:
1. פתח **"סגירת יום"**
2. רואה סיכום של כל הפעילות
3. הדפס להוכחה או לארכיון
4. **חשוב:** צור ידנית את תעודות המשלוח ב-SAP לפי הרשימה
