## Stack טכנולוגי

### Backend
- **Node.js 24** + **Express** / **Fastify**
- **mssql** - חיבור ל-SQL Server של SAP (קריאה)
- **axios** - SAP Service Layer (כתיבה)
- **Socket.IO** - עדכונים בזמן אמת
- **Zod** - validation
- **Prisma** / **Knex** - ORM למסד הנתונים הלוגיסטי

### Frontend
- **React 18** + **Vite** + **TypeScript**
- **TailwindCSS** + RTL
- **TanStack Query** - data fetching
- **Zustand** - state management
- **React Router v6**

### Mobile (לנהגים)
- **PWA** - אותו codebase כמו Frontend, בלייאאוט מובייל
- **Service Worker** - עבודה offline
- **Geolocation API** - מיקום בזמן אמת

### תשתית
- **SQL Server** - מסד נתונים לוגיסטי (נפרד מ-SAP)
- **Docker Compose** - deploy מקומי
- **PM2** - process manager

## כללי עסקיים חשובים

1. **הפרדה חשבונאית מלאה** - כל חברה שומרת על ה-ח.פ שלה
2. **איחוד לוגיסטי בלבד** - ההזמנות והחשבוניות נשארות ב-SAP נפרד
3. **עקיבות SAP** - כל מסמך חייב להישמר ב-SAP
4. **אסור כפילויות** - ליקוט פעם אחת, משלוח פעם אחת
5. **דינמי** - הזמנות, ביטולים וחזרות יכולים להתווסף במהלך היום

## הפעלה (Development)

```bash

npm install
npm run dev

# Frontend
cd frontend
npm install
npm run dev

# Mobile (PWA) - אותו שרת כמו Frontend
# נטען במובייל דרך /driver
```
